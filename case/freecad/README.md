# FCL_case.FCStd

- **Printed_parts_edit_these:** rear and front shells, both cell cradles and the button plungers, as solid bodies imported from case/print/*.step.
  - To change one: select it, then PartDesign > Create body, then use it as the base feature and add pads/pockets/fillets on top.
  - Or use Part booleans.
- **Machined_parts:** the right-hand block (solid) and the left blocks (mesh). The parametric blocks are in docs/mech/freecad. Both still show the earlier A/B block, not the common block now on the board.
- **Reference_meshes_do_not_edit:** PCB, cells, TFT, camera, ribbon, caps and slugs, kept light for fit checks.
- The case geometry itself is generated by case/assembly/build_case.py (CadQuery) because it follows the PCB. Big layout changes are best made there; the FreeCAD file is for local edits and export.
- Regenerate: flatpak run --command=freecadcmd org.freecad.FreeCAD case/assembly/freecad_case.py case case/freecad/FCL_case.FCStd
- Colours are not stored (built headless).
